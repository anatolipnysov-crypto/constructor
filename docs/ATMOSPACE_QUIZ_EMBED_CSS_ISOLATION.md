# Изоляция стилей квиза на сайте клиента

## Результат

Готовый код квиза не должен менять оформление других блоков Tilda или элементов клиентского сайта.

```text
готовый код вставлен в HTML-блок
→ все стили ограничены корнем .atmospace-quiz-embed
→ внешний сайт сохраняет своё оформление
→ квиз сохраняет своё оформление
```

## Что ограничивается

Корнем квиза ограничиваются:

- переменные оформления;
- общий `box-sizing`;
- кнопки и поля;
- все классы квиза;
- состояния `hover`, `focus` и выбранных ответов;
- правила внутри адаптивных `@media`-блоков.

## Что сохраняется без изменения

- `@keyframes` и их шаги `from` / `to`;
- имена анимаций;
- содержимое `@font-face`, если оно появится позднее;
- HTML, JavaScript и прямые HTTPS-ссылки на изображения.

## Совместимость

Изоляция применяется только к переносимому коду для Tilda или другого HTML-блока. Полный HTML-файл остаётся самостоятельной страницей и использует исходные стили.

## Безопасность

- код не обращается к хостингу конструктора;
- не создаёт страницу клиента;
- не загружает CSS или HTML на сервер;
- не меняет настройки Tilda;
- не затрагивает Метрику, партнёрскую атрибуцию или регистрацию.

## UI acceptance

No internal technical copy is visible in user-facing UI. All visible text must be product/human copy, not developer/debug/system wording.
