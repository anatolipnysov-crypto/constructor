# Код квиза для сайта клиента

## Правильная продуктовая схема

Конструктор не публикует и не размещает страницы клиентов.

```text
клиент собирает квиз
→ связывает его с Атмосферой и своим счётчиком Метрики
→ получает готовый переносимый код
→ вставляет код в Tilda T123 или HTML-блок своего сайта
→ размещает страницу на своём домене и хостинге
```

На 200–300 клиентов не создаются отдельные Cloudflare Pages, KV-хранилища, домены или Access-политики.

## Что выдаёт конструктор

После подготовки доступны два результата:

1. Код для вставки в HTML-блок.
2. Полный HTML-файл как запасной вариант для собственного хостинга или разработчика.

Основной результат — код для вставки.

## Tilda

В Tilda пользователь:

1. добавляет блок T123 «HTML-код»;
2. вставляет код целиком;
3. сохраняет блок;
4. публикует страницу на своём домене.

Код содержит необходимые HTML, CSS и JavaScript в одном фрагменте и не содержит `doctype`, `html`, `head` или `body`, поэтому предназначен именно для вставки внутрь страницы.

## Картинки

Конструктор не загружает картинки на хостинг клиента и не создаёт собственное хранилище для каждой страницы.

- прямые HTTPS-ссылки на медиасервер сохраняются в коде без изменения;
- браузер посетителя загружает картинки по этим ссылкам;
- временные адреса `blob:` и локальные `file:` не допускаются, потому что после закрытия конструктора они перестанут работать;
- медиасервер Сергея остаётся отдельным общим контуром хранения изображений.

## Атмосфера и Метрика

Подготовка кода по-прежнему:

- создаёт безопасную связь страницы с Атмосферой;
- закрепляет партнёрскую атрибуцию;
- подключает счётчик Метрики;
- обеспечивает цели посещения, ответов, завершения квиза и перехода к регистрации;
- сохраняет рекламные параметры до регистрации;
- не помещает разрешение Метрики, партнёрский код или другие защищённые значения в готовый код.

Регистрация, CAPTCHA, подключение Telegram/MAX, платежи и серверные цели выполняются на стороне Атмосферы.

## Чего нет

В этом контуре отсутствуют:

- кнопка «Опубликовать»;
- адрес `/q/...`;
- хостинг страниц в конструкторе;
- Cloudflare KV для клиентских страниц;
- Cloudflare Access для публикации;
- автоматическое создание инфраструктуры на каждого клиента;
- перенос картинок на новый хостинг.

## UI acceptance

No internal technical copy is visible in user-facing UI. All visible text must be product/human copy, not developer/debug/system wording.
