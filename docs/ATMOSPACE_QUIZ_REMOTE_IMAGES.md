# Изображения в длинном квизе

## Результат

Редактор позволяет добавить:

- одну обложку квиза;
- необязательное изображение к каждому вопросу;
- короткое текстовое описание каждого изображения.

## Где хранятся файлы

Конструктор не загружает и не хранит изображения клиента.

```text
изображение хранится на общем медиасервере
→ оператор вставляет прямую HTTPS-ссылку
→ ссылка сохраняется в проекте квиза
→ готовый код содержит эту ссылку
→ браузер посетителя загружает файл с медиасервера
```

На каждый клиентский сайт не создаётся отдельное хранилище.

## Допустимые ссылки

Разрешены только прямые ссылки с протоколом HTTPS.

Не принимаются:

- `http:`;
- `blob:`;
- `file:`;
- `data:`;
- ссылки с логином или паролем внутри адреса;
- текст, который не является адресом.

Пустое поле допустимо: квиз может работать без изображений.

## Готовый код

- обложка загружается вместе с первым экраном;
- изображения вопросов загружаются по мере прокрутки;
- адреса и параметры HTTPS-ссылок сохраняются;
- описание изображения попадает в `alt`;
- HTML-символы экранируются;
- изображения не превращаются в base64 и не копируются на другой сервер.

## Интерфейс

В редакторе используются человеческие поля:

- «Прямая HTTPS-ссылка на обложку»;
- «Описание обложки»;
- «Прямая HTTPS-ссылка на изображение»;
- «Описание изображения».

При неверной ссылке редактор показывает понятную ошибку и не готовит итоговый код.

## UI acceptance

No internal technical copy is visible in user-facing UI. All visible text must be product/human copy, not developer/debug/system wording.
